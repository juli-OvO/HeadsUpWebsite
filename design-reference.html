Heads Up Design Reference — Webflow Implementation Guide
Cobalt — Primary
50500 — #2955AC800
Primary CTA#2955AC
Hover state#234A97
Hard shadow#1D3D7E
Webflow: Add as Global Swatches. Name them exactly cobalt-500, cobalt-600, etc. Use cobalt-500 for all primary buttons + eyebrows. cobalt-600 on :hover. cobalt-700 as the hard bottom box-shadow color. Never use cobalt-400 or lighter as text — contrast fails WCAG AA.
Sky — Accent only
Highlight ink#97BDF1
sky-300 (#97BDF1) is used exclusively for the inline text highlight marker (background-image gradient on a Span). Not used as button fills, section backgrounds, or borders. sky-100/200 appear on dark cobalt panels as muted text color.
Moss — Secondary (30%)
Moss base#5C7667
Secondary tone — appears ~30% of the site. Use for: alt Sticker badge tone, "See programs" button, eyebrow label on alternate sections (moss-700). moss-800 (#34453B) = hard button shadow. Never mix cobalt + moss on the same element.

Page bg#F4F7FC
Border#D6DCE7

ink-50 = page background (not pure white — slightly blue-gray). ink-900 = all headings + main body text. ink-600 = secondary paragraph / lead text. ink-200 = visible card borders. ink-400 = placeholder initials, captions, faint dividers.

First paragraph under a section heading or in the page hero sub-line. In Webflow: <p> with class lead. Color is ink-600 — notably lighter than body copy. Max-width ~560px inside .wrap.

Always appears above an H2, never below. In Webflow: <div> or <p> with class eyebrow. Color alternates: cobalt-500 on standard sections, moss-700 on alternate sections. Never use an H tag here — purely decorative label.

lg — 0 20px 48px rgba(23,48,99,.16)
modal / elevated panel
btn hard — 0 4px 0 cobalt-700
3D press effect on all buttons
Hard shadow (0 Xpx 0 color) creates a "tactile press" illusion — not a blur, just a solid offset. In Webflow: add Box Shadow with Blur = 0, Spread = 0, Y offset = 4px, color = cobalt-700. On :hover interaction → Move Y -2px + increase Y offset to 6px. On :active → Move Y +1px + decrease Y offset to 2px.

Highlight Marker
Helping students look up.
Inline <span> · background-image gradient only · no padding change
Webflow: Select the word(s) in the heading → Wrap in a <span> → class highlight-mark. In Custom CSS: .highlight-mark { background-image: linear-gradient(180deg, transparent 54%, #97BDF1 54%, #97BDF1 94%, transparent 94%); padding: 0 .06em; }. The 54%–94% range creates the highlighter-pen look sitting below the baseline.

Webflow: <hr> element, height 0, border-top only. Class divider with combo class for strength. Never use a background-color approach — the rgba opacity is intentional for all backgrounds. On-dark variant is only used inside cobalt-gradient mission/hero panels.

3-col gap: 32–48px (CSS grid)

Webflow: Don't use Webflow's 12-col grid — most layouts use a custom .wrap div (max-width 1120px, auto margins, 28px horizontal padding). Sections use Flexbox or CSS Grid set via Custom CSS. Mobile: all multi-column layouts collapse to 1 column below 768px. The scrollsnap on mobile is set via Custom CSS, disabled on desktop.
